# Export Preview Typography Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let Export Preview render body text as small as 6px and independently control fenced-code font size down to 4px and fenced-code line height.

**Architecture:** Extend the existing normalized `ExportStyle` contract with two fenced-code numeric fields and apply all three typography values in the shared standalone HTML builder used by HTML, PDF, and image exports. Keep the controls in the existing Export Preview draft flow so cancellation remains non-persistent and confirmation reuses the current save path.

**Tech Stack:** TypeScript, React 19, Vitest, Testing Library, React-Markdown, Tauri 2, CSS generated by `buildExportHtml`

## Global Constraints

- Body size range is 6–24px with a 1px step.
- Fenced-code size range is 4–24px with a 1px step and a 12px default.
- Fenced-code line-height range is 0.8–2.2× with a 0.1× step and a 1.6× default.
- Code size and line height apply to fenced code blocks only; inline code remains `0.875em` relative to surrounding body text.
- HTML, PDF, paginated image, and continuous image exports consume the same normalized style.
- Existing saved export choices survive additive migration; missing new fields receive defaults.
- Export Preview cancellation does not persist draft changes.
- Theme changes preserve body size, fenced-code size, and fenced-code line height.
- Do not add global Settings fields, per-format typography, or a code font-family control.

- `src/lib/exportDocument.ts`: owns `ExportStyle`, defaults, normalization, preset application, persistence, and generated export CSS.
- `src/lib/exportDocument.test.ts`: verifies bounds, legacy migration, persistence, preset preservation, and standalone HTML CSS.

- `src/shell/ExportPreviewTab.tsx`: renders the body-size control and connects code-control patches to the live draft.
